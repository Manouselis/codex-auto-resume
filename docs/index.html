From an armed chat to a confirmed continuation

Each conversation has its own recovery queue. You can disarm it from the desktop panel at any time.

  1. 1

    Choose a conversation

    Use Add conversation to arm the chat and open it in Codex. An eligible idle chat receives one continue. A running chat keeps working.

  2. 2

    Wait for included allowance

    If armed work stops at the five-hour limit, Auto-Resume waits for the reset and checks fresh usage before it sends a continuation.

  3. 3

    Continue in Codex

    The original conversation receives the continuation. Auto-Resume checks that the new turn started and removes normally completed chats from the queue.

When recovery pauses

Live continuation was verified on Ubuntu with Codex runtime 0.166. Windows and macOS installer tests use isolated data.

Verification and test scope
  • Allowance and billingWeekly exhaustion, paid usage and unknown billing routes block continuation.
  • Changes in the original chatApprovals, cancellation, task budgets and newer manual work can stop recovery.
  • Unconfirmed deliveryWhen Codex does not confirm a submission, Auto-Resume pauses the chat for inspection.
