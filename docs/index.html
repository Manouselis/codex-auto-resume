Upgrading from an older version

Windows
If Check for updates fails in an older copy, close it and run the Windows installer above. The app shows its version in the footer.
Ubuntu and macOS
If the older app cannot offer the update, install the Ubuntu package over it or replace the macOS app in Applications.

From an armed chat to a confirmed continuation

Each conversation has its own recovery queue. You can disarm it from the desktop panel at any time.

  1. 1

    Choose a conversation

    Use Add conversation to open a chat in Codex and add it to the queue as Armed ahead. Start or keep working in Codex.

  2. 2

    Wait for included allowance

    Normal manual turns leave a chat queued. After a confirmed five-hour interruption, Auto-Resume waits for the reset and checks fresh included usage.

  3. 3

    Continue in Codex

    The original conversation receives the continuation. Auto-Resume confirms the new turn started and removes the chat when automatic recovery completes normally.

When recovery pauses

Live continuation was verified on Ubuntu with Codex runtime 0.166. Windows and macOS installer tests use isolated data.

Verification and test scope
  • Allowance and billingWeekly exhaustion, paid usage and unknown billing routes block continuation.
  • Changes in the original chatApprovals, cancellation, task budgets and newer manual work after an interruption can stop recovery.
  • Unconfirmed deliveryWhen Codex does not confirm a submission, Auto-Resume pauses the chat for inspection.
